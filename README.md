# Portfolio Đinh Hương Linh

Trang cá nhân Portfolio của **Đinh Hương Linh** - Sinh viên Kinh tế Đối ngoại (Chất lượng cao) - Trường Đại học Ngoại thương (FTU).

## 🎨 Design System
- **Vibe:** Soft Warm Vintage, Editorial Elegance, Warm Pastel Aesthetics.
- **Màu sắc chủ đạo:**
  - Nền chính: `#FAF4ED` (Warm Light Cream)
  - Card & Background phụ: `#F4E5DC` / `#EFE2D8` (Blush Pink / Creamy Nude)
  - Chữ chính & Tiêu đề: `#2D231E` (Dark Warm Espresso)
  - Điểm nhấn & CTA: `#C85A3C` / `#B85238` (Terracotta Red)
  - Chi tiết viền & bóng mờ: `#D8A492` (Rose Gold / Soft Taupe)
- **Typography:**
  - Tiêu đề: *Cormorant Garamond* / *Playfair Display*
  - Nội dung: *Plus Jakarta Sans*

## 📁 Cấu trúc file
- `index.html`: Toàn bộ mã nguồn trang Portfolio với Tailwind CSS, Lucide icons, responsive cho Mobile, Tablet & Desktop.

## 🚀 Cách mở và xem
Mở trực tiếp file `index.html` trong trình duyệt bằng:
```bash
open /Users/huogwlinh/.gemini/antigravity/scratch/dinh-huong-linh-portfolio/index.html
```
hoặc khởi chạy web server nhẹ nếu cần:
```bash
npx serve /Users/huogwlinh/.gemini/antigravity/scratch/dinh-huong-linh-portfolio
```
